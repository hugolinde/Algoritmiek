# Algoritmiek
Een recursief algoritme is een algoritme dat zichzelf aanroept om een kleiner deel van het probleem op te lossen. Het idee is: om een groot probleem op te lossen, los ik eerst een kleiner probleem op dat er sterk op lijkt.

Een recursief algoritme bestaat meestal uit:
- Basisgeval (stopt de recursie)
- Recursieve aanroep (dezelfde functie roept zichzelf aan met kleinere invoer)

## Recursieve problemen
- Fibonacci-reeks – elk getal is de som van de twee voorgaande
- Toren van Hanoi
- Quick sort
- Knapsack probleem
- Gewogen interval planning
